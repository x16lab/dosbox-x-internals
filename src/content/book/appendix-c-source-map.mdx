# Appendix C — Annotated Source Map {#appendix-c-annotated-source-map}

*A cross-reference from source file to subsystem to the chapter(s) that explain it, and back. Useful in both directions: if you're reading a chapter and want to open the file it's discussing, or if you're browsing the DOSBox-X source tree and want to know whether — and where — this book covers a file you've found. Built incrementally alongside the chapters; every entry below is a file actually cited in the book so far.*

*(Source references are against `joncampbell123/dosbox-x`, commit `192c1756`, cloned 2026-07-25. File locations may drift as the project moves.)*

## By Subsystem {#by-subsystem}

- **Scheduler / event queue** — `src/dosbox.cpp`, `src/hardware/pic.cpp`, `src/hardware/timer.cpp` → @chapter(main-loop-and-event-scheduler)
- **Memory model** — `include/paging.h`, `include/regs.h`, `src/ints/ems.cpp`, `src/ints/xms.cpp` → @chapter(memory-model-and-address-translation)
- **CPU cores** — `src/cpu/core_normal.cpp` (interpreter) → @chapter(interpreter-core); `src/cpu/core_dynrec.cpp` and `src/cpu/core_dynrec/*.h` (dynamic recompiler), `src/cpu/core_dyn_x86.cpp` and `src/cpu/core_dyn_x86/*.h` (original x86-only dynamic core) → @chapter(dynamic-recompilation)
- **Interrupts and exceptions** — `include/cpu.h`, `src/cpu/cpu.cpp`, `src/hardware/pic.cpp` → @chapter(interrupts-exceptions-pic)
- **VGA/SVGA** — `src/hardware/vga_crtc.cpp`, `vga_seq.cpp`, `vga_gfx.cpp`, `vga_attr.cpp`, `vga_memory.cpp`, `vga_draw.cpp`, `vga_misc.cpp`, `src/ints/int10_modes.cpp` → @chapter(vga-emulation)
- **DMA and PIT (beyond the system timer)** — `src/hardware/dma.cpp`, `src/hardware/pcspeaker.cpp`, port `0x61` handling in `src/hardware/keyboard.cpp` → @chapter(dma-and-pit)
- **Sound** — `src/hardware/sblaster.cpp`, `src/hardware/adlib.cpp`, `src/hardware/gus.cpp`, `include/midi.h`, `src/gui/midi_*.h` → @chapter(sound)
- **Configuration** — `src/misc/setup.cpp` → @section(dosbox-x-architecture/configuration-as-its-own-layer)
- **Frontend / host integration** — `src/gui/sdlmain.cpp`, `src/gui/render.cpp`, `src/output/output_surface.cpp` (and sibling `output_*.cpp` backends) → @section(dosbox-x-architecture/why-start-here) (brief); @chapter(host-abstraction-sdl) (full treatment)
- **Input** — `src/hardware/keyboard.cpp`, `src/gui/sdl_mapper.cpp` → @section(host-abstraction-sdl/input-keyboard-mouse-and-joystick-three-different-shapes)
- **Audio handoff** — `src/hardware/mixer.cpp` → @section(host-abstraction-sdl/audio-a-pull-based-handoff-and-dosbox-x-s-first-thread-boundary)
- **Cross-module communication** — `src/hardware/iohandler.cpp`, `include/callback.h` → @section(dosbox-x-architecture/how-modules-talk-to-each-other)
